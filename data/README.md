
# Data

## Overview

This project uses the publicly available Kickstarter dataset published by
[Web Robots](https://webrobots.io/kickstarter-datasets/).

The raw Kickstarter data are not redistributed through this repository.
Instead, this directory documents the data source, analytical filtering
process and resulting dataset used in the project.
